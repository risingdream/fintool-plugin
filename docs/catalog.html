2. 핵심 항등식 (근사 없음)

연초 인출 구조 $A_{t+1} = (A_t - C_t)(1+R_t)$ 를 누적수익 G_t = \prod_{s<t}(1+R_s) 로 디플레이트하면 정확히

A_n / G_n = A_0 - \sum_{t=0}^{n-1} \frac{C_t}{G_t}

즉 n년 시점 고갈 ⟺ S_n \equiv \sum_{t<n} C_t/G_t \geq 25. $S_n$은 단조증가라 최초통과시점이 곧 고갈 시점입니다. 30년 전체:

  • $E[S_{30}] = 29.02$억, \mathrm{SD}(S_{30}) = 10.18억 (적률은 정확히 계산 가능)
  • $E[S] = 29.0 > 25$ — 인출 스트림의 실효 현가가 이미 원금을 넘습니다

모델 설정 (실질 기준)
  • 명목수익률 R ~ 로그정규분포, 산술평균 5.5%, 표준편차 12%
  • 물가상승률 2%로 고정(확정적) → 실질수익률 r = (1+R)/1.02 − 1
  • 로그수익률 환산: σ_log² = ln(1+(0.12/1.055)²) ≈ 0.01285 → σ_log ≈ 11.34%

μ_log(명목) = ln(1.055) − 0.5·σ_log² ≈ 4.71%
μ_log(실질) = μ_log(명목) − ln(1.02) ≈ 2.73%

  • 인출액: 매년 초 1.2억(명목), 매년 2.5%씩 증가 → 실질로는 매년 (1.025/1.02−1)≈0.49%씩 증가
  • 매년 초 인출 후 남은 잔액에 그 해 실질수익률 적용 (연금-선불 방식)
  • 고갈 = 인출 시점에 잔액이 인출액보다 작아지는 경우
실행 가능한 시뮬레이션 코드
import numpy as np

np.random.seed(42)
n_sims = 50_000
n_years = 30

A0 = 2_500_000_000   # 25억
W0 = 120_000_000     # 1.2억
w_growth_real = 1.025/1.02 - 1   # 실질 인출증가율 ≈0.49%

mu_log_real = np.log(1.055) - 0.5*np.log(1+(0.12/1.055)**2) - np.log(1.02)
sigma_log = np.sqrt(np.log(1+(0.12/1.055)**2))

# 실질 로그수익률 경로 생성
log_returns = np.random.normal(mu_log_real, sigma_log, size=(n_sims, n_years))
real_returns = np.exp(log_returns) - 1

ruin_year = np.full(n_sims, -1)   # -1 = 생존
balance = np.full(n_sims, A0, dtype=float)
alive = np.ones(n_sims, dtype=bool)

for t in range(n_years):
    withdrawal = W0 * (1 + w_growth_real) ** t
    remaining = balance - withdrawal
    newly_ruined = alive & (remaining <= 0)
    ruin_year[newly_ruined] = t + 1          # 몇 년차에 고갈됐는지(1-indexed)
    alive[newly_ruined] = False
    balance[alive] = remaining[alive] * (1 + real_returns[alive, t])

ruin_prob = (ruin_year != -1).mean()
print(f"자산 고갈 확률: {ruin_prob:.1%}")

ruined_years = ruin_year[ruin_year != -1]
print("고갈 시점 분포(연차) 백분위:",
      np.percentile(ruined_years, [10,25,50,75,90]))

# 수익률 순서 위험: 초기 5년 평균 실질수익률 비교
first5_avg = real_returns[:, :5].mean(axis=1)
ruined_mask = ruin_year != -1
print("고갈 경로 초기5년 평균수익률:", first5_avg[ruined_mask].mean())
print("생존 경로 초기5년 평균수익률:", first5_avg[~ruined_mask].mean())

import matplotlib.pyplot as plt
from scipy import stats
import pandas as pd

# 파라미터 설정
initial_asset = 2_500_000_000  # 25억 원
initial_withdrawal = 120_000_000  # 1.2억 원
withdrawal_growth = 0.025  # 인출액 연 2.5% 증가
expected_return = 0.055  # 기대수익률 5.5%
volatility = 0.12  # 변동성 12%
inflation_rate = 0.02  # 물가상승률 2%
years = 30
num_simulations = 10000

np.random.seed(42)

# 몬테카를로 시뮬레이션
depleted_simulations = []
survived_simulations = []
depletion_times = []

for sim in range(num_simulations):
    assets = initial_asset
    withdrawal = initial_withdrawal
    depleted = False
    
    annual_returns = []
    annual_assets = []
    
    for year in range(years):
        # 연초 인출
        assets -= withdrawal
        
        # 자산 고갈 체크
        if assets <= 0 and not depleted:
            depleted = True
            depletion_times.append(year)
        
        # 수익률 생성 (정규분포)
        annual_return = np.random.normal(expected_return, volatility)
        annual_returns.append(annual_return)
        
        # 자산에 수익률 적용
        if assets > 0:
            assets *= (1 + annual_return)
        
        annual_assets.append(max(assets, 0))
        
        # 다음 해 인출액 증가
        withdrawal *= (1 + withdrawal_growth)
    
    # 경로 분류
    if depleted:
        depleted_simulations.append({
            'returns': annual_returns,
            'assets': annual_assets,
            'early_returns': annual_returns[:5]
        })
    else:
        survived_simulations.append({
            'returns': annual_returns,
            'assets': annual_assets,
            'early_returns': annual_returns[:5]
        })

# 통계 계산
depletion_rate = len(depleted_simulations) / num_simulations * 100

print("은퇴 자산 고갈 위험 분석")

print(f"초기 인출액: {initial_withdrawal:,.0f}원")
print(f"기대수익률: {expected_return*100}% | 변동성: {volatility*100}%")
print(f"물가상승률: {inflation_rate*100}% | 시뮬레이션 수: {num_simulations:,}")

print(f"\n【고갈 확률】")
print(f"자산 고갈 확률: {depletion_rate:.2f}%")

print(f"\n【순서 위험 분석: 초기 5년 누적수익률】")

if depleted_simulations:
    depleted_early = np.array([
        np.prod([1 + r for r in sim['early_returns']]) - 1 
        for sim in depleted_simulations
    ])
    print(f"\n고갈된 경로 (n={len(depleted_simulations)}):")
    print(f"  평균: {depleted_early.mean()*100:.2f}%")
    print(f"  중위: {np.median(depleted_early)*100:.2f}%")
    print(f"  표준편차: {depleted_early.std()*100:.2f}%")
    print(f"  범위: {depleted_early.min()*100:.2f}% ~ {depleted_early.max()*100:.2f}%")

if survived_simulations:
    survived_early = np.array([
        np.prod([1 + r for r in sim['early_returns']]) - 1 
        for sim in survived_simulations
    ])
    print(f"\n생존한 경로 (n={len(survived_simulations)}):")
    print(f"  평균: {survived_early.mean()*100:.2f}%")
    print(f"  중위: {np.median(survived_early)*100:.2f}%")
    print(f"  표준편차: {survived_early.std()*100:.2f}%")

  • 예: 2년물-3년물 구간은 큰 폭으로 내려가고 5년물 이상은 작게 움직인다면, 헤지 효과 감소
2) 동적 재조정 필요
  • 시간 경과에 따라 포트폴리오의 듀레이션이 감소 (콘벡시티, 쿠폰 영향)
  • 선물 가격 변화로 인한 듀레이션 변동
  • 주기적 리밸런싱이 필수이지만, 거래비용 증가
3) 선물 롤오버 위험
  • 3년물 선물이 만기가 되면 새로운 계약으로 전환 필요
  • 롤오버 시점에 따라 가격 변동 발생 (캐리 코스트 손실)
4) 금리 방향 반대일 경우 손실
  • 금리가 예상과 달리 상승하면: -105억 원 → -750억 원으로 손실 확대
5) 선물 마진과 자금 조달 비용
  • 초기 마진, 유지 마진 자금이 지속적으로 필요
  • 마진 이자 비용 발생
  • 현금 흐름 관리 복잡성
6) 시스템적 위험
  • 금융 시장 시스템 리스크 발생 시 선물 시장 유동성 급감 가능
  • 강제 청산 위험

1. 필요한 선물 계약 수와 방향 계산
기본 공식
필요한 현물 추가량 = (목표 MD - 현재 MD) × 포트폴리오 시가
                  = (7.5 - 4.2) × 500억
                  = 1,650억 원분 위험도

선물 한 계약 현물가 = (112.50 / 100) × 1억 = 1.1250억 원

선물 한 계약의 위험도 = 1.1250억 × 8.6 = 9.675억 원

필요한 계약 수 = 1,650 / 9.675 ≈ 170.5계약

2. 금리 50bp 하락 시 손익 비교
A. 헤지 전(현물 포트폴리오만)
DV01 = 포트폴리오 시가 × MD / 10,000
     = 500억 × 4.2 / 10,000 
     = 210만 원/bp

50bp 하락 시 손익 = 210만 × 50 = 1.05억 원
B. 헤지 후(현물 + 선물 170계약 매수)

170계약의 DV01 = 170 × 96.75만 = 1.6448억 원/bp

선물 손익(50bp 하락) = 1.6448억 × 50 = 8.224억 원

헤지 후 순손익 = 1.05억 + 8.224억 = 9.274억 원

3. 듀레이션 오버레이의 한계
1) 곡률(Convexity) 무시
  • DV01은 금리 변화에 선형을 가정하지만, 실제는 비선형
  • 금리 변화가 50bp 이상 크면 오차 확대
  • 더 정확하려면 : 손익 = DV01 × Δr + ½ × Convexity × (Δr)²
2) 기저 위험(Basis Risk)
  • 3년 국채선물 ≠ 포트폴리오 구성 채권들의 평균 특성
  • 선물은 표준화(CTD: Cheapest-to-Deliver 가정)
  • 신용도, 만기, 유동성 미스매치로 추적오차 발생
3) 포트폴리오 동적 변화
  • 이표 지급, 상환, 손익실현, 신규 투자 시 MD 자동 변화
  • 목표 MD 유지 시 주기적 재조정(Rebalancing) 필요
  • 실제 듀레이션 드리프트 발생
4) 선물 롤오버(Roll) 비용
  • 3년 국채선물은 만기가 3~4개월로 짧음
  • 주기적으로 만기 물자를 교체해야 함
  • 롤오버 시 기저 손실(Roll Yield 악화)
5) 금리곡선 변화(Non-Parallel Shift)
  • MD는 전 구간 평행이동 가정
  • 실제: 단기와 장기 금리가 다르게 움직임
  • 키 레이트 듀레이션(Key Rate Duration) 사용이 더 정확
6) 파이낸싱 비용 차이(Carry)
  • 현물 채권 보유 비용 ≠ 선물 포지션 자금조달 비용
  • 레포 금리, 거래비용 차이로 장기 성과 악화
7) 재조정 빈도 트레이드오프

  • 너무 드물게 조정: 추적오차↑
