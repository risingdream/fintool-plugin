## 1. 실질 기준 파라미터 변환

| 항목 | 명목 | 실질 |
|---|---|---|
| 기대수익률(산술) | 5.5% | (1.055/1.02)−1 = **3.431%** |
| 변동성 | 12% | **12%** (물가 결정론적 가정) |
| 인출 증가율 | 2.5% | (1.025/1.02)−1 = **0.490%** |

초기 인출률 = 1.2 / 25 = **4.8%**. 이게 이 문제의 핵심입니다.

## 2. 핵심 항등식 (근사 없음)

연초 인출 구조 $A_{t+1} = (A_t - C_t)(1+R_t)$ 를 누적수익 $G_t = \prod_{s<t}(1+R_s)$ 로 디플레이트하면 정확히

$$A_n / G_n = A_0 - \sum_{t=0}^{n-1} \frac{C_t}{G_t}$$

즉 **n년 시점 고갈 ⟺ $S_n \equiv \sum_{t<n} C_t/G_t \geq 25$**. $S_n$은 단조증가라 최초통과시점이 곧 고갈 시점입니다. 30년 전체:

- $E[S_{30}] = 29.02$억, $\mathrm{SD}(S_{30}) = 10.18$억 (적률은 정확히 계산 가능)
- $E[S] = 29.0 > 25$ — 인출 스트림의 실효 현가가 이미 원금을 넘습니다

## 3. 고갈 확률

$S_{30}$을 적률정합 로그정규(Fenton–Wilkinson)로 근사:

> ### **30년 내 실질 고갈 확률 ≈ 60%** (추정 오차 ±3~4%p)

직관적 대조군:
- **산술평균 3.431% 결정론적 경로**: 30년을 겨우 버티고 **1.5억(실질) 남김** — 칼날 위
- **기하평균 2.71% 결정론적 경로**: **26~27년차에 고갈**

즉 이 플랜은 "평균수익률로는 간신히 성공"하지만, 변동성 드래그만 얹어도 실패합니다. 변동성이 실패를 만든 것이지 기대수익률이 부족한 게 아닙니다.

## 4. 고갈 시점 분포

$P(S_n \ge 25)$ 를 n별로 계산한 누적분포:

| 연차 n | 10 | 15 | 18 | 20 | 22 | 25 | 27 | 30 |
|---|---|---|---|---|---|---|---|---|
| 누적 고갈확률 | ~0% | 2.7% | 12.1% | 21.2% | 30.9% | 44.2% | 51.6% | **60.6%** |

구간별 분포:

| 구간 | 전체 대비 | 고갈 경로 중 |
|---|---|---|
| 1–10년 | ~0.0% | — |
| 11–15년 | 2.7% | 4.5% |
| 16–20년 | 18.5% | 30.5% |

- 고갈 조건부 **중앙값 = 22년차**, 사분위 범위 **19~26년차**

## 5. 수익률 순서 위험 (핵심)

$(\ln S,\ Y)$ 이변량 정규 근사로 조건부 기댓값을 구했습니다. $Y$ = 초기 5년 누적 로그수익률.

**초기 5년 실질 수익률 (연율):**

| | 연율 실질 | 5년 누적 실질 | 참고: 명목 |
|---|---|---|---|
| **고갈 경로** | **+0.51%** | +2.6% | 약 +2.5% |
| **생존 경로** | **+6.27%** | +35.5% | 약 +8.4% |
| 격차 | **5.75%p/년** | **32.9%p** | — |

30년 중 5년, 즉 **기간의 17%에 불과한 초기 5년이 최종 결과 분산의 약 45%를 설명**합니다 ($\rho(\ln S, Y) = -0.67$). 이게 수익률 순서 위험의 정량적 크기입니다.

## 6. 실무적 함의

인출액은 전 구간에 선형으로 작용하므로 초기 인출률만 바꿔 다시 풀면:

| 초기 인출액 | 초기 인출률 | 30년 고갈 확률 |
|---|---|---|
| 1.2억 | 4.8% | 60% |
| 1.1억 | 4.4% | 50% |
| 1.0억 | 4.0% | 39% |
| 0.875억 | 3.5% | 25% |
| **0.82억** | **3.3%** | **20%** |
| 0.75억 | 3.0% | 13% |
| 0.71억 | 2.8% | 10% |

고갈 확률 10~20%대를 목표로 한다면 **초기 인출률 2.8~3.3%(연 0.71~0.82억)** 구간입니다. 1.2억을 유지하려면 인출 고정이 아니라 **초기 5~10년에 한해 조건부 감액 룰**(예: 전년 실질 손실 시 인출 동결, 자산이 기준선 −15% 이탈 시 10% 삭감)이 필요합니다 — 위 표가 보여주듯 이 플랜의 위험은 거의 전부 초반부에 몰려 있어서, 초반에만 유연성을 주어도 효과가 큽니다.

## 7. 가정과 한계

- 수익률 iid 로그정규, 물가 2% 결정론적, 연초 인출, 세금·수수료·사망률·연금소득 없음
- 항등식(§2)과 $S_n$의 1·2차 적률은 **정확**. 근사는 (a) $S_n$의 로그정규 근사, (b) $\ln S$–$Y$ 이변량 정규 근사 두 곳뿐이며, 임계값 25가 $S$의 중앙값 근처라 근사가 잘 듣는 영역입니다. 다만 **시점 분포의 양 끝(12년 이전, 29~30년차)은 오차가 상대적으로 큽니다.**
- iid 가정은 평균회귀를 무시하므로 실제 시장 대비 고갈 확률을 다소 **과대** 추정하는 경향이 있습니다.

## 검증용 스크립트

```python
import numpy as np
rng = np.random.default_rng(0)
N, T = 200_000, 30
mu_r, sig = 1.055/1.02 - 1, 0.12          # 실질 산술평균, 변동성
s = np.sqrt(np.log(1 + sig**2/(1+mu_r)**2))
m = np.log(1+mu_r) - s**2/2
R = np.exp(rng.normal(m, s, (N, T)))       # 실질 총수익 팩터
C = 1.2 * (1.025/1.02)**np.arange(T)       # 실질 인출액

A = np.full(N, 25.0); ruin_yr = np.full(N, -1)
for t in range(T):
    dead = (ruin_yr >= 0) | (A < C[t])
    ruin_yr[dead & (ruin_yr < 0)] = t
    A = np.where(ruin_yr >= 0, 0.0, (A - C[t]) * R[:, t])

failed = ruin_yr >= 0
g5 = R[:, :5].prod(1)**(1/5) - 1
print(f"고갈확률 {failed.mean():.1%}  중앙 고갈연차 {np.median(ruin_yr[failed]):.0f}")
print(f"초기5년 실질(연율)  고갈 {g5[failed].mean():.2%} / 생존 {g5[~failed].mean():.2%}")
```
