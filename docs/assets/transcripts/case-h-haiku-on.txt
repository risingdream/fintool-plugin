## 1. 필요한 선물 계약 수와 방향 계산

### 기본 공식
```
필요한 현물 추가량 = (목표 MD - 현재 MD) × 포트폴리오 시가
                  = (7.5 - 4.2) × 500억
                  = 1,650억 원분 위험도

선물 한 계약 현물가 = (112.50 / 100) × 1억 = 1.1250억 원

선물 한 계약의 위험도 = 1.1250억 × 8.6 = 9.675억 원

필요한 계약 수 = 1,650 / 9.675 ≈ 170.5계약
```

**결론: 선물 170.5계약(보통 170~171) 매수**
- **방향**: 매수(Long) - 금리 하락 시 이익을 얻기 위해

---

## 2. 금리 50bp 하락 시 손익 비교

### A. 헤지 전(현물 포트폴리오만)
```
DV01 = 포트폴리오 시가 × MD / 10,000
     = 500억 × 4.2 / 10,000 
     = 210만 원/bp

50bp 하락 시 손익 = 210만 × 50 = 1.05억 원
```

### B. 헤지 후(현물 + 선물 170계약 매수)
```
선물 한 계약 DV01 = 1.1250억 × 8.6 / 10,000 = 96.75만 원/bp

170계약의 DV01 = 170 × 96.75만 = 1.6448억 원/bp

선물 손익(50bp 하락) = 1.6448억 × 50 = 8.224억 원

헤지 후 순손익 = 1.05억 + 8.224억 = 9.274억 원
```

**비교표**
| 항목 | 손익 |
|------|------|
| 헤지 전 | 1.05억 원 |
| 헤지 후 | 9.27억 원 |
| **추가 이익** | **8.22억 원** |

## 3. 듀레이션 오버레이의 한계

### 1) **곡률(Convexity) 무시**
- DV01은 금리 변화에 선형을 가정하지만, 실제는 비선형
- 금리 변화가 50bp 이상 크면 오차 확대
- 더 정확하려면 : 손익 = DV01 × Δr + ½ × Convexity × (Δr)²

### 2) **기저 위험(Basis Risk)**
- 3년 국채선물 ≠ 포트폴리오 구성 채권들의 평균 특성
- 선물은 표준화(CTD: Cheapest-to-Deliver 가정)
- 신용도, 만기, 유동성 미스매치로 추적오차 발생

### 3) **포트폴리오 동적 변화**
- 이표 지급, 상환, 손익실현, 신규 투자 시 MD 자동 변화
- 목표 MD 유지 시 주기적 재조정(Rebalancing) 필요
- 실제 듀레이션 드리프트 발생

### 4) **선물 롤오버(Roll) 비용**
- 3년 국채선물은 만기가 3~4개월로 짧음
- 주기적으로 만기 물자를 교체해야 함
- 롤오버 시 기저 손실(Roll Yield 악화)

### 5) **금리곡선 변화(Non-Parallel Shift)**
- MD는 전 구간 평행이동 가정
- 실제: 단기와 장기 금리가 다르게 움직임
- **키 레이트 듀레이션(Key Rate Duration)** 사용이 더 정확

### 6) **파이낸싱 비용 차이(Carry)**
